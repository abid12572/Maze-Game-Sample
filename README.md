\# Mouse Maze Game



A 3D maze game developed using Unity and C#.



\## About



The player controls a mouse through a maze and must collect cheese.



\## Features



\- 3D maze environment

\- Player movement using WASD

\- Collectible cheese

\- Floating cheese animation

\- Collision detection

\- Rigidbody-based player movement



\## Technologies



\- Unity

\- C#

\- Unity Input System

\- Git

\- GitHub



\## Controls



| Key | Action |

|-----|--------|

| W | Move Forward |

| S | Move Backward |

| A | Move Left |

| D | Move Right |



\## Project Structure



\- `Assets/` - Game assets and scripts

\- `Packages/` - Unity packages

\- `ProjectSettings/` - Unity project configuration
